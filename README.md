# Problem: Who is the application for, and what problem does it address? 
We created this application to learn the states and territories of India. 
Our group members are from India, and we have always wanted to learn the states and territories of India, so we decided to create an interactive game that is engaging and makes learning fun.
# Core function: What is the main thing a user can do? 
Answer the state or territory that is highlighted out of 4 options. You are also given a hint
When you get the state/territory correct, it becomes green on the map.
Once you finish getting tested on all the states/territories, the whole map will be green.
The progress bar at the bar will fill 100%- so you can track your progress.
#  Testing: Describe your tests of normal input, invalid input, reset or retry, and phone-sized display. State what happened. 
Normal input- The application works as expected and highlights the correct option you selected green which verifies that you are correct, and it tells you the capital and a fun fact about the state/territory.
Invalid output- if you select the incorrect option, it becomes red and the correct one becomes highlighted green, and it gives you info on the correct ones.
Reset or retry- there is a restart option in the corner if you want to restart from the beginning. When you select incorrect, the game lets you retry a few questions later to keep the scattered design consistent. 
Phone sized display- We tested the application on a mobile-sized screen to check whether the map, highlighted states or territories and four answer options were clearly visible and easy to select. 
#  Improvement: What did you change after testing or obtaining feedback, and why? 
We adjusted the design, so it is cleaner and more professional.
We also adjust the borders so that they are more accurate when the state/territory is highlighted. 
#  Limitations: What does the application not do, or what would need further validation before real-world use? 
The application is designed mainly for educational purposes to help users learn and identify the states of India on a map. However, it has some limitations:
The game focuses on identifying Indian states and does not teach other geographical details such as capitals, rivers or neighboring countries. 
It may not include different difficulty levels for beginners and advanced learners. 
Users will need an internet connection. 
The map and state boundaries should be checked for geographical accuracy
Future improvements could include a scoring system, timer, different difficulty levels, and more detailed information about each state. 
Before real world educational use, the accuracy of the map, state names, boundaries, answers should be validated. 
# AI use and contributions: Which AI tools did you use? What did your group contribute, decide, and verify? 
We initially used Google AI Studio to help create our game, but during testing, our group identified several problems. The map of India was not accurate.
We also noticed that the game sometimes marked correct answers as incorrect and moved to the next question too quickly, giving users little time to see the results.
As a group, we discussed these issues and decided to use Visual Studio Code to improve the application.
We also decided to change the name of the game to make it more suitable for our project.
We requested a feature that allows users to drag the map left, right, up and down while zoomed in, making it easier to navigate and identify smaller states and territories. 
We also focused on correcting the answers and improving the timing between questions.  
Our group contributed by identifying the problems, suggesting improvements, and making decisions about game design and functionality.
We tested the game to check whether the highlighted states matched the correct answers, whether the map could be moved easily, and whether users had enough time to see the results before moving to the next question.
